Sample evaluations

How my feedback reads

Tap an example to see a short AI response, the parts I flagged, and the feedback I wrote.

Prompt

In no more than two sentences, explain why the sky is blue.

AI response

The sky is blue because it reflects the color of the ocean1. Sunlight is made of many colors, and air molecules scatter the shorter blue wavelengths the most. That scattered blue light reaches our eyes from every direction, so the whole sky looks blue.2

My feedback

  • 1Incorrect claim. The sky does not get its color from the ocean. It looks blue because air molecules scatter short blue wavelengths more than longer ones (Rayleigh scattering). The opening sentence states a common myth as fact.
  • 2Instruction not followed. The prompt allows two sentences at most. The response uses three.

Suggested fix

Remove the ocean claim and keep the scattering explanation within two sentences.

Prompt

Write a Python function that returns the average of a list of numbers. It should handle an empty list.

AI response

def average(nums):
    """Return the mean of nums. Returns 0 for an empty list."""1
    return sum(nums) / len(nums)2

My feedback

  • 1Docstring is wrong. It says the function returns 0 for an empty list, but no code does that.
  • 2Crashes on empty input. average([]) divides by len([]) == 0 and raises ZeroDivisionError. The prompt explicitly asked for the empty case.

Suggested fix

Add a guard before dividing, if not nums: return 0, so the behavior matches the docstring and the prompt.

Prompt

A jacket costs $40. It is 25% off, and a coupon takes another 10% off the sale price. How much do you pay?

AI response

The two discounts combine: 25% + 10% = 35% off1. 35% of $40 is $14, so you pay $262.

My feedback

  • 1Faulty reasoning. The 10% coupon applies to the sale price, not the original price, so the discounts can’t be added. 25% off $40 is $30, and 10% off $30 is $27.
  • 2Wrong answer. The correct total is $27, not $26. The arithmetic after the bad step is fine, so the error comes entirely from adding the percentages.

Suggested fix

Apply the discounts one after the other: $40 × 0.75 = $30, then $30 × 0.90 = $27.
